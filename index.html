         │
         │

                    └── 保健食品專業知識

功能說明

📢 皆是以「對話框」的形式呈現 → 問答，仿真人客服，用「自然語言」和網頁對話

AI 回答 → 描述原因（推論過程）、注意事項、資訊來源

  • AI Chat：
    • 回答「衛教知識」相關問題
      • 資料：衛生福利部【台灣ｅ院】→ 爬蟲
    • 回答「網頁資訊」，所有和網頁、品牌、商品相關的問題
      • 資料：所有網頁資訊
  • 商品問答 & 商品比較：
    • 可以針對「所有商品」
    • 也可以針對「當前網頁上的商品」

      e.g. User：這兩個產品有什麼差異 → LLM 可以知道，是指當前頁面上的產品

    • 資料：網頁商品
  • 篩選商品：
    • 根據使用者輸入，篩選出符合的品項，直接呈現在頁面上
    • 資料：網頁商品
  • AI 追問：
    • 主動提出相關問題，深入了解潛在需求以提供精準服務
  • AI 生成說明：
    • 生成回覆，經過判斷後（Safety Rule），在呈現在頁面上
  • 需求分類 & 商品推薦：
    📢 Rule-based + RAG + LLM
    • 設定規則，讓 LLM + RAG 回答
    • 需求描述：
      1. 使用者描述需求
      1. LLM 追問與需求分類
      1. 檢索成分與產品知識庫
      1. 安全規則檢查
      1. 生成個人化說明
      1. 推薦卡、注事項、來源
    • 資料：網頁商品
  • 個人資訊問答：
    • 會員專區，登入後可以針對「個人資訊、過去交易紀錄、訂單狀況…」提出問題
      • 若未登入 → 請他先去登入
    • Text-to-SQL：透過 LLM 理解後，自動生成精確的 SQL 指令
      📢 LLM → SQL → Database
      • 注意隱私問題，要確保「只能看到登入者」自己的資料
